# Portfólio — Isadora Gularte

Portfólio pessoal desenvolvido com Vite, React, TypeScript, Tailwind CSS e shadcn/ui.

## Como rodar localmente

Pré-requisito: Node.js e npm instalados ([instalar com nvm](https://github.com/nvm-sh/nvm#installing-and-updating)).

```sh
# Clone o repositório
git clone <URL_DO_REPOSITORIO>

# Acesse a pasta do projeto
cd <NOME_DO_PROJETO>

# Instale as dependências
npm i

# Inicie o servidor de desenvolvimento
npm run dev
```

## Tecnologias utilizadas

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS
- Framer Motion
